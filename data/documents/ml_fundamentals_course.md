# Course: Machine Learning Fundamentals

## Provider: Coursera (Andrew Ng)

## Duration: 11 weeks

## Skills Taught
- Machine Learning
- Linear Regression
- Logistic Regression
- Neural Networks
- SVM
- Decision Trees
- Clustering
- Anomaly Detection
- Recommender Systems

## Prerequisites
- Python
- Linear Algebra
- Statistics

## Description
Comprehensive introduction to machine learning algorithms. Covers supervised and unsupervised learning, best practices, and practical applications.
