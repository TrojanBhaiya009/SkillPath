# Job Description: Mobile Developer

## Company: AppStudio

## Role Overview
Build high-quality native and cross-platform mobile applications.

## Required Skills
- JavaScript
- TypeScript
- React Native
- Git
- Redux
- React Navigation
- Jest
- Detox
- Xcode
- Android Studio
- App Store Deployment
- Play Store Deployment

## Preferred Skills
- Swift
- Kotlin
- Expo
- Fastlane
- CodePush
- Firebase
- Analytics
- Push Notifications
- Deep Linking

## Responsibilities
- Build and maintain React Native applications
- Implement native modules when needed
- Optimize app performance and bundle size
- Write unit, integration, and e2e tests
- Manage app store releases with Fastlane
- Implement analytics and crash reporting
- Collaborate with designers and backend engineers
- Ensure platform-specific UI/UX guidelines

## Experience
- 3+ years mobile development
- React Native production experience
- Native iOS/Android experience a plus
